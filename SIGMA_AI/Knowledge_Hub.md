# SIGMA AI — SigmaCare Knowledge Hub

> Návrh týmové znalostní báze a spolupráce (27. 10. 2026). Podklad: uživatelem dodané schéma „SigmaCare Knowledge Hub“.

## Role
- **Metodický garant / Product Owner:** priority, schvalování metodik, kvalita, backlog.
- **Analytici:** analýzy procesů a dat, KPI, zadání vývoje, AI kontext.
- **Vývojáři:** Python, DAX, Power BI, integrace, dokumentace.
- **AI analytici / Agent Designers:** prompty, agenti, scénáře, evaluace, kontextové balíčky.
- **Testeři / QA:** scénáře, validace, chyby, schvalování nasazení.
- **Správce znalostí:** struktura, šablony, standardy, dokumentace.

## Navržená struktura
1. `01_Methodologies/` — metodiky, KPI, procesy, standardy.
2. `02_Analytics/` — analytické postupy, DAX/Python vzory, zadání.
3. `03_AI_Agents/` — prompty, scénáře, konfigurace a evaluace.
4. `04_Development/` — kód, integrace, technická dokumentace.
5. `05_Testing/` — scénáře, očekávané výsledky, chyby.
6. `06_Work_In_Progress/` — rozpracovaná zadání, návrhy, otázky.
7. `07_Templates/` — šablony, checklisty, předávací balíčky.
8. `08_Decisions/` — schválená rozhodnutí, změny metodik, release notes.

## Workflow
Analýza a návrh → uložení podkladů a GitHub Issue → implementace a Pull Request → QA a validace → schválení a publikace.

## Osobní a sdílená prostředí
Každá role pracuje ve vlastním schváleném pracovním prostředí ChatGPT. Sdílené projekty ChatGPT slouží pro týmovou diskusi; GitHub pro verzované metodiky a kód; SharePoint/Microsoft 365 pro řízené dokumenty.

## Bezpečnost
- Soukromé repozitáře pro interní obsah, role a princip nejmenších oprávnění, MFA/2FA, code review a audit změn.
- **Žádná osobní, pacientská, klientská ani jiná citlivá data do veřejného GitHubu.**
- Před použitím AI ověřit smluvní, právní a technické podmínky, přístupová oprávnění a pravidla pro anonymizaci/pseudonymizaci.
- Schéma je koncepční návrh, nikoli potvrzení již zavedených kontrol.
